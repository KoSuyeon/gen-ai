# 문의 유형 분류 라벨링 가이드 (승승장구몰 고객지원본부)

> 버전 v1.2 · 2026-05-01 · 문의 유형 분류기 학습/검수 기준

## 1. 목적
고객 CS 문의를 **10개 표준 유형** 중 하나로 일관되게 분류하기 위한 기준이다.
RAG 라우팅과 분류기 파인튜닝의 정답(ground truth)으로 사용한다.

## 2. 유형 정의
| 유형 | 정의 | 핵심 신호어 |
|---|---|---|
| 배송문의 | 배송 진행상황·도착시기·송장·미수령·배송지 변경 | 언제 와요, 송장, 어디쯤, 안 왔어요 |
| 주문결제 | 결제 오류·승인·입금확인·쿠폰적용·중복결제·영수증 | 결제, 입금, 쿠폰 적용, 두 번 결제 |
| 취소 | **발송 전** 주문을 무르는 요청 | 취소, 아직 안 보냈, 발송 전 |
| 반품 | **수령 후** 상품을 돌려보내는(반환) 요청 | 반품, 돌려보내, 회수 |
| 교환 | 동일 상품의 다른 옵션/정상품으로 **바꾸기** | 교환, 바꿔, 다른 색/사이즈로 |
| 환불 | **이미 취소/반품된 건의 금액** 처리·시점·금액 | 환불, 돈 언제, 입금 안 됨, 차감 |
| 재입고 | 품절 상품의 재입고 여부·알림 | 품절, 재입고, 언제 들어와요 |
| 상품정보 | 상품 자체의 소재·사이즈·사용법·호환 등 | 소재, 실측, 호환, 인덕션, 세탁 |
| 회원멤버십 | 등급·적립금·쿠폰·로그인·회원정보·탈퇴 | 등급, 적립금, 비밀번호, 탈퇴 |
| 기타 | 위에 속하지 않는 것(세금계산서·대량구매·제휴·수신거부 등) | 세금계산서, 대량, 제휴, 수신거부 |

## 3. 경계(혼동) 규칙 — 가장 중요
실제로 가장 많이 틀리는 구간이다. 아래 우선순위를 따른다.

1. **취소 vs 환불**: 상품이 **아직 발송 전**이면 `취소`. 이미 취소/반품되어 **돈 처리**가 쟁점이면 `환불`.
   - "주문 취소하고 돈 돌려줘(아직 안 보냄)" → **취소**
   - "취소됐다는데 돈 언제 와요" → **환불**
2. **반품 vs 환불**: 상품을 **돌려보내는 행위**가 핵심이면 `반품`. 반품 후 **금액**이 쟁점이면 `환불`.
   - "반품할게요 / 회수 언제 와요" → **반품**
   - "반품한 거 환불 언제" → **환불**
3. **반품 vs 교환**: **돈을 돌려받으면** `반품`, **다른 물건으로 바꾸면** `교환`.
   - "마음에 안 들어 다른 걸로" → **교환**(바꿈) / "그냥 환불" → **반품**
4. **배송문의 vs 취소**: 문장의 **주된 의도**로 판단. "지금 어디예요?"가 핵심이면 `배송문의`,
   "그래서 취소할래요"가 핵심이면 `취소`.

## 4. 라벨링 절차
1. PII(고객명·연락처)는 분류에 사용하지 않으며, 학습 데이터에서는 마스킹한다.
2. 한 문의에 여러 의도가 섞이면 **가장 핵심적인 요청** 하나로 라벨링한다.
3. 판단이 어려우면 위 경계 규칙을 적용하고, 그래도 모호하면 리드에게 에스컬레이션한다.

## 5. 예시
- "어제 시킨 거 아직이면 취소해 주세요" → `취소`
- "반품했는데 환불이 안 들어와요" → `환불`
- "사이즈 큰 걸로 바꿔주세요" → `교환`
- "이거 인덕션 되나요?" → `상품정보`
- "품절인데 언제 들어와요?" → `재입고`
